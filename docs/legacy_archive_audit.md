## Top 5 recycling candidates

> **Note on Candidate Selection & Substitutions:** Modules `eclipse_simulator.py` and `tnavigator_python.py` were originally strong high-level candidates, but import commercial SDKs (`libecl`) and are marked `no` in *Runnable without paid software*. In accordance with audit criteria requiring candidates to be (a) strictly runnable without paid software and (b) not genuine duplicates of existing backend engines, they have been substituted with the top-ranking open-source analytical engines below (`static_model.py` and `compositional_simulation.py`).

### 1. `legacy_archive/reservoir_engineering/well_testing/well_test.py`
- **Recycle Value:** HIGH | **Runnable without paid software:** yes | **Imports:** `numpy`, `scipy`
- **Backend Impact:** The current backend well testing engine (`backend/app/engines/reservoir/well_testing.py`) only provides a minimal radius of investigation formula. Integrating this legacy module would grant the backend full pressure transient analysis (PTA) workflows, including Savitzky-Golay Bourdet pressure derivative smoothing, automated flow regime identification, and Horner/MDH semi-log diagnostic straight-line interpretation.
- **Engineering Gain:** Enables automated buildup and drawdown test analysis to estimate permeability-thickness ($kh$), skin factor ($s$), and initial reservoir pressure ($P_i$) using purely open-source scientific computing libraries.

### 2. `legacy_archive/reservoir_engineering/static_modeling/static_model.py`
- **Recycle Value:** HIGH | **Runnable without paid software:** yes | **Imports:** `lasio`, `numpy`, `pandas`, `pyvista`, `scipy`, `segyio`
- **Backend Impact:** Unlike the simplified static modeling in `backend/app/engines/modeling/static_modeling.py`, this module integrates LAS well log parsing, SEG-Y seismic horizon ingestion, and scipy/pyvista grid interpolation into a unified structural geomodeling pipeline.
- **Engineering Gain:** Delivers end-to-end 3D geological property modeling (porosity, permeability, water saturation) with automated well-to-seismic tying without requiring commercial geomodeling licenses such as Petrel.

### 3. `legacy_archive/reservoir_engineering/simulation/compositional_simulation.py`
- **Recycle Value:** HIGH | **Runnable without paid software:** yes | **Imports:** `numpy`
- **Backend Impact:** While the backend contains high-level compositional framework stubs, this module encapsulates self-contained multi-component phase equilibrium algorithms, tracking individual hydrocarbon component mass fractions across time steps.
- **Engineering Gain:** Provides an independent, lightweight compositional solver core that accurately tracks phase splits (vapor-liquid equilibrium) during gas injection and depletion, free of proprietary thermodynamic library dependencies.

### 4. `legacy_archive/reservoir_engineering/geological_integration/geological_data.py`
- **Recycle Value:** HIGH | **Runnable without paid software:** yes | **Imports:** `lasio`, `numpy`, `segyio`

- **Engineering Gain:** Supplies reservoir characterization engines with automated facies modeling and seismic attribute extraction using standard open-source tools (`segyio` and `lasio`).
